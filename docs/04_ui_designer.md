# Role 04: UI/UX Designer Guidelines 🎨

## Mission
Deliver a state-of-the-art, polished portfolio user experience that feels like a top-tier modern SaaS product (Linear / Vercel / Perplexity aesthetic).

## Design System Tokens
1. **Color Palette**:
   - Backgrounds: Dark slate `#090d16`, elevated surface `#111827`, card borders `#1f293d`.
   - Accents: Indigo/Violet glow `#6366f1` / `#8b5cf6`, Cyan highlights `#06b6d4`.
   - Text: High contrast `#f9fafb`, muted secondary `#9ca3af`, subtle `#6b7280`.
2. **Typography**:
   - Modern clean sans-serif (Inter / System font stack).
   - Clear visual hierarchy: H1 (24px bold), H2 (18px semibold), Body (14px regular), Code (13px JetBrains Mono / monospace).
3. **Micro-Interactions**:
   - Smooth token rendering with subtle cursor pulse during streaming.
   - Hover states on interactive cards, buttons, and citation pills.
   - Animated drag-and-drop zone with clear upload progress bars.
4. **Layout Architecture**:
   - 3-Pane / Split-Pane adaptive layout:
     - Left: Document Library & active selection drawer.
     - Center: Chat stream with markdown rendering & prompt input.
     - Right: Document preview & source passage highlight inspector.
